# Lembaran Fakta Syarikat: Microsoft
## Company Fact Sheet: Microsoft

**Entiti:** Microsoft Corporation (Redmond, Washington, USA)  
**Skop Penyelidikan:** Microsoft Azure, Microsoft 365, Azure OpenAI Service, Pusat R&D Herzliya  
**Penilaian Status:** Keterlibatan Bersejarah dengan Sekatan Akses Ketenteraan & Semakan Bebas 2025–2026

---

### 1. Prinsip Penyelidikan: Nuansa & Integriti Fakta
Kempen ini tidak menyamakan Microsoft secara bulat-bulat dengan Google atau Amazon. Demi mempertahankan kredibiliti, kami mendokumentasikan kedua-dua aspek:
1. **Bukti pembekalan perisian dan infrastruktur Azure kepada kementerian pertahanan Israel.**
2. **Bukti bantahan dalaman, siasatan bebas, dan tindakan Microsoft menamatkan akses tentera kepada teknologi pengawasan tertentu pada September 2025.**

---

### 2. Hubungan Yang Didokumenkan
* **Pusat Penyelidikan Herzliya:** Dibuka pada 1991, pusat R&D Microsoft di Israel mempunyai hubungan pengambilan bakat yang rapat dengan veteran Unit 8200 (unit risikan isyarat tentera).
* **Perjanjian Perusahaan Sektor Pertahanan:** Microsoft membekalkan sistem operasi Windows, suite produktiviti Microsoft 365, dan perkhidmatan awan Azure kepada Kementerian Pertahanan Israel melalui kontrak perolehan kerajaan jangka panjang.
* **Bukan Pemenang Project Nimbus:** Microsoft kalah dalam bidaan Project Nimbus kepada Google dan AWS pada April 2021, bermakna Microsoft tidak tertakluk kepada klausa tegar 'tiada boikot' Nimbus.

---

### 3. Bantahan Kakitangan: "No Azure for Apartheid"
* Ratusan pekerja Microsoft menggerakkan kempen dalaman membantah penggunaan Azure dalam sistem ketenteraan.
* Pada Ogos 2025, pekerja Microsoft menduduki ibu pejabat Redmond dan mendirikan zon kempen bebas menuntut penamatan kontrak pertahanan.
* Microsoft memecat beberapa pekerja pada akhir 2024 dan 2025 susulan demonstrasi dalaman yang dianggap melanggar etika syarikat.

---

### 4. Tindakan Sekatan & Pembaharuan Polisi (2025–2026)
* **Penamatan Akses Teknologi Pengawasan (September 2025):**  
  Laporan berwibawa daripada Business & Human Rights Resource Centre mendedahkan bahawa Microsoft **menghentikan akses tentera Israel kepada alat pengawasan khusus Azure** yang didapati digunakan untuk pengawasan beramai-ramai di Gaza dan Tebing Barat, berasaskan pelanggaran Polisi Penggunaan Boleh Diterima (*Acceptable Use Policy*).
* **Semakan Hak Asasi Manusia Bebas:**  
  Lembaga Pengarah Microsoft melantik penilai luar bebas untuk menilai kesan hak asasi manusia akibat penggunaan teknologi Azure oleh tentera asing.
* **Garis Panduan Tadbir Urus Baharu (Jun 2026):**  
  Microsoft memperkenalkan semakan keselamatan negara yang lebih ketat sebelum memeterai kontrak pertahanan serta melindungi saluran pemberi maklumat (*whistleblower*) dalaman.

### 6. Alternatif Sumber Terbuka Yang Boleh Digunakan Rakyat Malaysia
* **Sistem Operasi (Ganti Windows):** Pasang **Debian, Ubuntu LTS, atau Linux Mint** (bebas yuran lesen dan bebas telemetri rahsia).
* **Suite Pejabat (Ganti Microsoft 365):** Beralih ke **LibreOffice** atau **OnlyOffice Desktop Editors**.
* **Identiti & Pengesahan (Ganti Azure AD / Entra ID):** Gunakan **Keycloak** (sistem pengurusan capaian identiti sumber terbuka standard industri).
